# TradeNote

A trade note is a daily journal where we record our trades, making it easy to review, analyze, and track performance over time.

## Overview

TradeNote is a comprehensive trading journal application designed to help traders document, track, and analyze their trading activities. Whether you're a day trader, swing trader, or long-term investor, TradeNote provides the tools you need to maintain detailed records and gain insights into your trading performance.

## Features

- 📝 **Daily Trade Logging** - Record trades with detailed information (entry, exit, position size, P&L)
- 📊 **Performance Analytics** - Analyze your trading statistics and metrics over time
- 📈 **Trade History** - Easy-to-review journal of all your trades
- 🎯 **Performance Tracking** - Monitor your progress and identify patterns in your trading
- 💡 **Trading Insights** - Get actionable insights from your trade data

## Technology Stack

- **Frontend**: JavaScript (62.2%)
- **Backend**: C# (35.5%)
- **Styling**: CSS (2%)
- **Markup**: HTML (0.3%)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) - For running the JavaScript frontend
- [.NET Framework](https://dotnet.microsoft.com/) - For running the C# backend

### Installation

1. Clone the repository:
```bash
git clone https://github.com/TChoppa/TradeNote.git
cd TradeNote
```

2. Install frontend dependencies:
```bash
npm install
```

3. Build and run the backend:
```bash
dotnet build
dotnet run
```

4. Start the frontend application:
```bash
npm start
```

## Usage

1. Open the application in your browser
2. Create a new trade entry with the following information:
   - Entry price and time
   - Exit price and time
   - Position size
   - Trade type (long/short)
   - Notes and observations
3. View your trading journal and performance metrics
4. Analyze your trading patterns and statistics
